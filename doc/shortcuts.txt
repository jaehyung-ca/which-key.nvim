1. INTRODUCTION                                          *shortcuts-introduction*

shortcuts is a standalone, zero-dependency manager for Neovim keybindings. It:

  - registers shortcuts (wrapping |vim.keymap.set|) and tracks their metadata;
  - shows a popup of available continuations when you start a key sequence;
  - provides a live fuzzy search over all known bindings;
  - keeps a raw-keystroke "panic buffer" to diagnose accidental input
    ("what did I just press that went weird?"), including a macro-recording
    guard.

==============================================================================
2. REQUIREMENTS                                          *shortcuts-requirements*

Neovim 0.12 or newer. No external plugins.

==============================================================================
3. SETUP                                                        *shortcuts-setup*

>lua
    require("shortcuts").setup({
      delay = 200,          -- ms to wait before the popup appears
    })
<
setup() is optional for |shortcuts-register| (a lazy default config is used),
but it is required to activate the popup triggers and the keylog.

==============================================================================
4. REGISTERING BINDINGS                                      *shortcuts-register*

                                                       *shortcuts.register()*
require("shortcuts").register({spec})

{spec} is a single binding or a list of them. Each item:

    item[1]    (string)   left-hand side, e.g. "<leader>ff"
    item[2]    (any)      right-hand side: a function or a string (optional)
    desc       (string)   description shown in popup/search
    mode       (string|table)  default "n"
    group      (string)   marks a prefix node (omit item[2])
    <opts>     silent, noremap, nowait, expr, buffer, remap

>lua
    require("shortcuts").register({
      { "<leader>f",  group = "Find" },
      { "<leader>ff", function() vim.cmd("buffers") end, desc = "Buffers" },
      { "<leader>fg", ":Grep<cr>", desc = "Live grep" },
    })
<
==============================================================================
5. ANNOTATING BINDINGS                                       *shortcuts-annotate*

                                                       *shortcuts.annotate()*
require("shortcuts").annotate({spec})

Attach metadata to maps created elsewhere so they appear in the popup and
search. Registry-only and side-effect-free — it does not touch the live map.

>lua
    require("shortcuts").annotate({ gd = "Go to definition" })
    require("shortcuts").annotate({ { "gr", "References", mode = "n" } })
<
==============================================================================
6. THE POPUP                                                    *shortcuts-popup*

Press a registered prefix root (by default |<leader>| / |<localleader>|) and
pause: a popup lists the continuations. Keep typing to descend; a complete
binding executes; <Esc> or an unknown key cancels. Fast typists never see the
popup — it only appears after `delay` ms of hesitation.

                                                            *shortcuts.show()*
require("shortcuts").show([{prefix}], [{mode}])
    Open the popup for {prefix} (default leader). Powers |:Shortcuts|.

By default only leader-rooted prefixes trigger the popup. To opt non-leader
roots in, list them under `triggers` (see |shortcuts-config|). Note this can
shadow builtin commands beginning with that key.

==============================================================================
7. SEARCH                                                      *shortcuts-search*

                                                          *shortcuts.search()*
require("shortcuts").search()

Opens a live fuzzy picker (|matchfuzzypos|) over all registered/annotated
bindings. Type to filter; <C-n>/<C-p> or <Down>/<Up> to move; <CR> to run the
selection; <Esc> to cancel. Matching considers both the lhs and the
description.

==============================================================================
8. KEYSTROKE DIAGNOSTIC                                           *shortcuts-what*

                                                            *shortcuts.what()*
require("shortcuts").what()

Returns the last N raw keystrokes (the "panic buffer") as display lines; see
also |:ShortcutsWhat|. This is a verbatim ring recorded via |vim.on_key| — it
captures EVERY key, registered or not, which is what makes it useful for
diagnosing accidental input. Surprise-prone keys (q, R, operators, <C-a>) are
annotated. A macro-recording guard warns the moment |q| starts a recording,
the single most common cause of "it started doing weird things".

==============================================================================
9. COMMANDS                                                  *shortcuts-commands*

                                                                  *:Shortcuts*
:Shortcuts [prefix]      Open the popup for {prefix} (default leader).
                                                            *:ShortcutsSearch*
:ShortcutsSearch         Open the fuzzy search picker.
                                                              *:ShortcutsWhat*
:ShortcutsWhat           Show recent raw keystrokes (the panic buffer).

10. CONFIGURATION                                              *shortcuts-config*

Defaults: >lua
    {
      delay = nil,        -- ms before popup; nil falls back to &timeoutlen
      win = {
        border = "rounded",
        position = "bottom",
      },
      sort = "key",
      triggers = "auto",  -- "auto" = leader/localleader; or a list of extra
                          -- roots, e.g. { "g", "z" }
      presets = {},       -- annotate built-in shortcuts (see below). {}/false
                          -- = none; true = { "g", "lsp", "z", "windows" }; "all";
                          -- or a list, e.g. { "g", "lsp", "z", "brackets" }
      keylog = {
        enabled = true,
        max = 50,               -- raw keystrokes retained
        notify_recording = true,-- warn when a macro recording starts
        set_showcmd = true,     -- show pending operators/counts in the corner
      },
      search = {        -- :ShortcutsSearch float size
        height = 0.7,   -- max rows: fraction of editor (<=1) or absolute (>1)
        min_width = 80, -- floor on width, in columns
        max_width = 0.9,-- width cap: fraction (<=1) or absolute (>1)
      },
    }
<
The search float scrolls to keep the selected entry visible. Values <= 1 are a
fraction of the editor, > 1 are absolute cells; `height` is a ceiling and the
width fits the content between `min_width` and `max_width`.

Built-in presets ~                                            *shortcuts-presets*

`presets` ships curated annotations for Neovim's *built-in* shortcuts so they
become browsable and fuzzy-searchable. It is metadata only: each preset calls
|shortcuts.annotate()|, never `vim.keymap.set`, so your native shortcuts are
untouched. Available sets: >

    g         g-prefix: gg, gd, gi, gu/gU, gq, gv, display motions, change list
    lsp       Neovim 0.11 LSP defaults: grn, gra, grr, gri, grt, grx, gO
    z         folds (zf/zo/zR/zM), scroll (zz/zt/zb), spelling (zg/z=)
    windows   window management under <C-w>
    brackets  [ and ] motions: unmatched parens, sections, methods, diffs, diags
<
Surface them on demand: >

    :Shortcuts g        " menu of built-in g-shortcuts
    :ShortcutsSearch    " fuzzy-search every binding, built-ins included
<
Presets do not auto-open a popup on `g`/`z` (see |shortcuts-limitations|); opt a
prefix into live triggers with `triggers = { "g", "z" }` if you accept that
some plugin-mapped g-commands may not replay.

==============================================================================
11. HIGHLIGHT GROUPS                                       *shortcuts-highlights*

All link to sensible defaults; override with |:highlight|.

    ShortcutsKey            popup: the key                  (Special)
    ShortcutsDesc           popup: a leaf description       (Normal)
    ShortcutsGroup          popup: a +group description     (Function)
    ShortcutsSeparator      popup: the " -> " separator     (Comment)
    ShortcutsSearchMatch    search: fuzzy-matched chars     (IncSearch)
    ShortcutsSearchSel      search: selected row            (Visual)
    ShortcutsSearchPrompt   search: the prompt marker       (Question)

==============================================================================
12. LIMITATIONS                                            *shortcuts-limitations*

  - Popup triggers default to leader roots; non-leader roots are opt-in and may
    shadow builtins (safe replay for builtin prefixes is not yet implemented).
  - Search executes the selection by feeding its lhs in the current mode, so a
    visual/insert-only binding must be invoked from that mode.
  - `expr` string-rhs maps register but their rhs is fed as-is.
  - Buffer-local map tracking is not yet supported.
